This repository is intended for high-agency coding-agent work.

## Operating Model

- `AGENTS.md`: how coding agents should work in this repository.
- `docs/product-intent.md`: what the product is trying to accomplish.
- `docs/approach.md`: the current stack, architecture, constraints,
  verification path, and delivery model.
- `docs/records/`: durable reasoning that future agents should inherit.

## Working Rule

Keep the product goal visible, keep the current approach accurate, and preserve
the reasoning behind durable choices.

When the user gives high-level intent, coding agents should translate it into a
real technical approach, implement the strongest coherent version, verify it
against project artifacts, and update the docs when project understanding
changes.
