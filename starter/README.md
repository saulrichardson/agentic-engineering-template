This repository uses a small documentation starter for high-agency coding-agent
work.

## Operating Model

- `AGENTS.md`: how coding agents should work in this repository.
- `docs/approach.md`: current project truth, including stack, architecture,
  constraints, verification, and delivery approach.
- `docs/product-intent.md`: product north star, user goals, desired outcomes,
  workflows, examples, and open questions.
- `docs/records/`: durable rationale, dated decisions, caveats, tradeoffs, and
  lessons future agents should inherit.

## Working Rule

Keep the goal visible, keep the current approach accurate, and record durable
reasoning when future agents should understand why a choice was made.

When the user gives high-level intent, coding agents should translate it into a
real technical approach, implement the strongest coherent version, verify it
against project artifacts, and update these docs when the understanding changes.
